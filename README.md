# Netflix Content Analysis Project

This project explores a Netflix dataset to uncover trends in content growth, global production, and genre popularity using Python.

## Key Insights
● **Content Growth Trends:** Analyzed growth over the years using release dates, showing a major surge post-2015.
● **Movies vs. TV Shows:** Movies still dominate the library, but TV Shows are on a steady rise.
● **Global Footprint:** USA and India lead the way in content contributions.
● **Genre Analysis:** Identified Documentaries and Stand-up Comedy as leading genres.

## Technical Skills Used
● **Data Cleaning:** Handled null values in 'Director', 'Cast', and 'Country'. 
● **Data Engineering:** Leveraged `release_year` for time-series analysis.
● **Visualizations:** Created aesthetic charts using Seaborn and Matplotlib with layout optimization (`tight_layout`).

## Files in this Repository
● `code.ipynb`: Main Jupyter Notebook with analysis.
● `netflix.csv`: The dataset used for this project.
